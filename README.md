# FeatherSlide

**Apresentações da suíte FeatherOffice, em Rust com interface nativa Iced** — leve, rápida e sem WebKit.

> **Em desenvolvimento.** O código ainda não foi publicado neste repositório.
> A versão alpha está prevista para **30/10/2026**.

## O que vem aí

- Slides e elementos com desfazer, layouts e texto formatado.
- Formas, ícones, SmartArt e WordArt.
- Gráficos e tabelas editáveis.
- Abre `.pptx` e `.odp`, grava o formato próprio `.fsdz` e exporta PDF.
- Verificação ortográfica local.
- Formato `.fsdz` com o histórico de versões guardado dentro do arquivo.

## Privacidade

Tudo roda na sua máquina: sem conta, sem login, sem telemetria.
